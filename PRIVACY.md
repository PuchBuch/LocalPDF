# Privacy policy

*Applies to the LocalPDF Windows app and the LocalPDF Chrome extension. Last updated: 25 November 2026.*

LocalPDF does not collect, send or share any data. It has no accounts, no analytics, no advertising and no servers.

## Your documents

The PDF files and pictures you open are read and edited only on your computer. So are the Excel and CSV files you choose, and the text you paste, to fill a table with. They are never uploaded, and neither are the values written into the table. Text recognition (OCR), the help, fonts and every other part of the editor are included in the app and run locally.

The Windows app blocks all outside network requests. The Chrome extension requests no permissions and its content security policy allows no connections to other sites, so it cannot send your files anywhere.

## Feedback

"Report a problem…" and "Feedback" only prepare a text. For a problem it starts with the version, the variant, Windows and the browser, the interface language and the kinds of recent errors; for an idea or a question, with the version and the variant. It never holds the content of a document or a file name, unless you write that in yourself. The list of recent errors is kept in memory only and is gone when you close LocalPDF.

LocalPDF sends nothing. When you press "Open the GitHub page", your browser opens GitHub with the text in the address, so GitHub receives it then. It becomes a public issue only when you send it there yourself, with your GitHub account. GitHub has its own [privacy statement](https://docs.github.com/site-policy/privacy-policies/github-general-privacy-statement).

## What is stored on your computer

- **Settings:** the interface language and the text recognition language.
- **Crash recovery:** while a document has unsaved changes, a copy with everything entered in it is kept so that it can be restored after a crash. The Windows app keeps it in `%APPDATA%\LocalPDF\recovery`, the extension in its own storage in your browser profile. The copy is not encrypted. It is deleted when you save or close the document normally. Documents opened with a password are never stored.

This data stays on your computer. Removing the extension deletes its storage. Uninstalling the Windows app leaves the folder `%APPDATA%\LocalPDF` in place; you can delete it by hand.
