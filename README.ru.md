# LocalPDF

Редактор PDF для Windows, который оставляет документы на вашем компьютере. Файлы никуда не загружаются: приложение блокирует внешние сетевые запросы, а распознавание текста работает локально.

**Это бета-версия.** Она хорошо проверена на сгенерированных файлах, но настоящих документов видела мало. Проверяйте результат и храните оригиналы. [Сообщить о проблеме](../../issues).

## Что умеет

- **Править текст на месте:** щёлкните по строке или слову и напечатайте новое. Жирность, курсив и цвет сохраняются, похожий шрифт подбирается сам.
- **Действительно удалять текст:** заменённый текст вырезается из сохранённого файла, а не просто закрывается, и результат проверяется.
- **Заполнять формы:** встроенные поля PDF или свои поля с текстом, галочками, крестиками, точками, подписями и картинками.
- **Находить поля:** добавляет пустые поля у линий и в рамках.
- **Распознавать сканы (OCR):** без интернета, на восьми языках. По сохранённому файлу работает поиск.
- **Работать со страницами:** удалять, поворачивать, переставлять, объединять PDF и картинки.
- **Подписывать от руки:** напечатать одну страницу, подписать её и поставить на её место скан или фото с телефона. Фото выпрямляется, обрезается по краю листа и очищается.
- **Открывать файлы с паролем** и сохранять защиту.
- **Ещё:** печать, извлечение текста в Markdown, восстановление после сбоя.
- **Языки:** English, Deutsch, Français, Español, Italiano, Polski, Українська, Русский.

## Установка

Скачайте `LocalPDF Setup` на странице [Releases](../../releases) и запустите.

Windows может предупредить о неизвестном издателе: установщик пока не подписан. Если вы доверяете этой загрузке, нажмите **Подробнее**, затем **Выполнить в любом случае**.

Чтобы открывать PDF двойным щелчком: правый щелчок по файлу → **Открыть с помощью** → **Выбрать другое приложение** → **LocalPDF** → **Всегда**.

## Расширение для Chrome

Тот же редактор работает и как расширение для Chrome. Оно не просит никаких разрешений и не допускает внешних соединений. В Chrome Web Store его пока нет. Чтобы попробовать, выполните `npm run build:extension`, откройте `chrome://extensions`, включите **Режим разработчика**, нажмите **Загрузить распакованное расширение** и выберите папку `out-extension`.

От приложения для Windows оно отличается так:

- PDF нельзя открыть двойным щелчком. Нажмите кнопку расширения на панели браузера и выберите файл.
- Копия для восстановления после сбоя лежит незашифрованной в профиле браузера. Документы, открытые по паролю, туда не попадают.
- Печать идёт через диалог браузера, и приложение не может узнать, напечатали вы или отменили.
- Проверено только в Chromium, но не в Edge и других браузерах.

## Ограничения

- **Картинки и сканы:** текст на картинке вырезать нельзя. Он только закрывается и остаётся в файле, приложение об этом предупреждает. Для сканов с секретными данными используйте печать в PDF и проверяйте результат.
- **Секретные документы:** после удаления важных данных поищите их в сохранённом файле другой программой для PDF. Не полагайтесь только на это приложение.
- **Исправленный текст** набирается одним из четырёх шрифтов (как Arial, Times New Roman, Calibri или Courier New), поэтому необычный шрифт будет заметно отличаться. Абзац не переносится заново: более длинное слово наедет на следующее.
- **Формы:** XFA и JavaScript внутри форм не поддерживаются.
- **Распознавание** хуже работает на бледных и кривых сканах и не читает рукопись. Перечитывайте результат.
- **Поиск полей** не находит ячейки для отдельных букв и может ошибаться на кривых сканах.
- **Печать** отправляет страницы картинками, поэтому очень большие документы готовятся долго.
- **Восстановление после сбоя:** пока есть несохранённые правки, копия лежит незашифрованной в `%APPDATA%\LocalPDF\recovery`. Она удаляется при сохранении и обычном закрытии. Документы, открытые по паролю, туда не попадают.

## Переводы

Переводы сделаны машинно и ещё не вычитаны носителями языка. Исправления приветствуются: файлы лежат в `src/renderer/src/i18n`.
